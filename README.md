One line: a software patch note for a bug in real life — the user's own teeth
biting the same spot on their cheek four times in one meal. The grader runs
`node main.ts`, which writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(fallback `/output`).
